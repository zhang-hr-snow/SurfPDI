# Benchmark data

Each TXT record contains three lines: protein ID, amino-acid sequence, and
binary binding labels. The sequence and label string have the same length.

| File | Manuscript name | Proteins |
|---|---|---:|
| `raw/txt/DNA-573_Train.txt` | DNA_573_Train | 573 |
| `raw/txt/DNA-129_Test.txt` | DNA_129_Test | 129 |
| `raw/txt/DNA_Test_181.txt` | DNA_181_Test | 181 |

Original filenames and data are unchanged. See the repository README for the
required structure and ESMC feature layouts.
